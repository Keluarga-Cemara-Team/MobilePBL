# 🚀 AntiBurnout - Mobile Subsystem

Repository modul aplikasi mobile dan web client untuk proyek PBL (**Project-Based Learning**) AntiBurnout.

## 📂 Struktur Modul
- `mobile/`: Source code aplikasi Flutter (Android, iOS, dan Web).
  - Silakan baca dokumentasi teknis lengkap di [`mobile/README.md`](./mobile/README.md).

## 🔗 Integrasi Backend
Modul ini terhubung secara otomatis dengan:
1. **WebPBL (Flask Backend)**: `http://127.0.0.1:5000`
2. **MachineLearningPBL API**: `http://127.0.0.1:8000`
3. **Database**: Google Cloud Firestore (Firebase)
